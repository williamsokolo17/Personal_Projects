# CodeAlpha Cyber Security Internship

This repository contains the cybersecurity projects completed during the CodeAlpha Cyber Security Internship.

## Projects

### Task 1: Basic Network Sniffer
A Python-based network packet sniffer developed using Scapy.

### Task 2: Phishing Awareness Training
A cybersecurity awareness presentation covering phishing attacks and prevention techniques.

### Task 3: Secure Coding Review
Security assessment of application code with identified vulnerabilities and remediation recommendations.

### Task 4: Network Intrusion Detection System (IDS)
Configuration and testing of an IDS using industry-standard tools and custom detection rules.
